# Крестики-нолики

Небольшая консольная игра на Python для практической работы по тестированию ПО.
Два игрока по очереди вводят номер свободной клетки от 1 до 9. В одной партии
может быть не более девяти успешных ходов.

## Запуск игры

Требуется Python 3.10 или новее.

```powershell
python game.py
```

Пустые клетки на поле обозначены числами, которые нужно вводить для хода.

## Автоматические тесты

Для тестирования отдельно выделены функции создания и отображения поля,
проверки ввода и хода, определения победы и ничьей. Тесты проверяют как
правильную работу, так и обработку букв, пустого ввода, чисел вне диапазона,
занятой клетки и других некорректных данных.

Установка pytest и запуск всех тестов:

```powershell
python -m pip install -r requirements.txt
python -m pytest -v
```

В папке `screenshots` находятся результаты трёх запусков:

1. `01-tests-passed.png` — все тесты прошли успешно.
2. `02-intentional-failure.png` — pytest нашёл специально внесённую ошибку.
3. `03-tests-passed-after-fix.png` — ошибка исправлена, все тесты снова проходят.
