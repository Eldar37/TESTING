# Крестики-нолики

Небольшая консольная игра на Python для практической работы по тестированию ПО.
Два игрока по очереди вводят номер свободной клетки от 1 до 9. В одной партии
может быть не более девяти успешных ходов.

## Запуск игры

Требуется Python 3.10 или новее.

```powershell
python game.py
```

Пустые клетки на поле обозначены числами, которые нужно вводить для хода.
